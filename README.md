# suban-web

Fine Art Wildlife Photography & Print Collection Platform built with Next.js 15, Drizzle ORM, Supabase, and Tailwind CSS.

## Features
- **High-Fidelity Wildlife Gallery & Shop**: Fine art prints and instant digital license downloads.
- **Museum-Grade Curation**: Custom framing, fine art paper specifications, and digital provenance deed certificates.
- **Collector Portal**: Account management, order tracking, downloadable digital assets, and high-res master files.
- **Admin Management Suite**: Full control over products, collections, pricing, stories, and store branding.
- **Responsive Architecture**: Modern cinematic UI with dark mode, fluid micro-interactions, and instant search.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/somthehit/suban-web.git
   cd suban-web
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Setup environment variables:
   Copy `.env.example` to `.env.local` and configure your database and authentication keys.

4. Run the development server:
   ```bash
   npm run dev
   ```
